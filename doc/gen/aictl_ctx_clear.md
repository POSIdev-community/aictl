## aictl ctx clear

Clear current aictl configuration

### Synopsis

Remove the entire local aictl context. Prompts for confirmation unless -y/--yes is set.

```
aictl ctx clear [flags]
```

### Examples

```
  aictl ctx clear
  aictl ctx clear -y
```

### Options

```
  -h, --help   help for clear
  -y, --yes    Skip confirmation prompt
```
