## aictl ctx show

Show current aictl context

### Synopsis

Print the local aictl context. Default output is human-readable; use --json or --yaml for machine-readable formats (mutually exclusive).

```
aictl ctx show [flags]
```

### Examples

```
  aictl ctx show
  aictl ctx show --json
  aictl ctx show --yaml
```

### Options

```
  -h, --help   help for show
      --json   Print context as JSON
      --yaml   Print context as YAML
```
